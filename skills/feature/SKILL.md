# Feature

## Overview

Starts a feature from a brainstorm to a planned branch: derives the codename and confirms it once with the operator, creates the branch, and writes the phase plan.

**Preflight:** run `bash "${CLAUDE_PLUGIN_ROOT}/scripts/preflight.sh"` as the first
action. A non-zero exit stops the skill: print its output verbatim and do nothing else.
